# NTS Dial

A compact macOS menu bar player for NTS Radio. Tune into NTS 1, NTS 2, or a curated set of Infinite Mixtapes from a tactile SwiftUI dial.

## Features

- Live NTS 1 and NTS 2 playback
- 16 Infinite Mixtape stations
- Menu bar controls and Now Playing integration
- Persistent station selection with audio and visual feedback

## Requirements

- macOS 14 or later
- Xcode 16 or later

## Run

Open `NTS Dial.xcodeproj` in Xcode, select the **NTS Dial** scheme, and run the app.
